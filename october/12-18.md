## Decisions

* Ludwig is not a building block. At most one sentence in related work.
* Goose harness agents stay single-agent workloads for now. Multi-agent systems will use agents that bring their own image and talk A2A, as in the kagent spike. This is a scope cut for now and does not change the thesis claim, which depends on the declared topology being enforced by the infrastructure.
* Agents called by other agents use A2A. The network policy only sees HTTP between pods, so the enforcement does not depend on the protocol.
* Nothing already built needs to be removed: the Goose adapter, loader, observability injection and the topology and paths code are generic.
